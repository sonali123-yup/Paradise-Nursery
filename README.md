# Paradise Nursery

Paradise Nursery is a React plant-shopping application where users can browse houseplants, add plants to a shopping cart, change quantities, and remove items.

## Features
- Landing page with company name and Get Started button
- About Us information
- Plant listing with product descriptions and prices
- Add to cart functionality
- Cart quantity updates and item removal
- Total item count and cart price calculation
- React and Redux Toolkit state management

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- CSS
